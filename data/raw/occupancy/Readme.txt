This folder contains 7 CSV files corresponding to seven buildings. Names are as

1. ACB : Academic Building
2. BH : Boy's Dormitory Buidling
3. DB : Dining Building
4. GH : Girl's Dormitory Building
5. LB : Library Building
6. LCB : Lecture Building
7. SRB : Facilties Building

---------------------------------------------------------------------------------------------------------------------------
---------------------------------------------------------------------------------------------------------------------------
1. Please refer to paper for further building details. The timestamp provided is in UNIX format.  While converting timestamps to Human readable format, mention timezone as "Asia/Kolkata" and set offset as +5:30 hours. 
2. If you are using Python or R, then use following readily available scritps for reading data
   Python: https://github.com/i-blend/i-blend.github.io/blob/master/py_scripts/read_energy_occupancy.py
        R: https://github.com/i-blend/i-blend.github.io/blob/master/r_scripts/read_energy_occupancy.R
